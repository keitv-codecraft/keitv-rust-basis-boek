# Refactoring

Refactoring betekent de code verbeteren zonder het gedrag te veranderen.

Een veilige volgorde is:

1. Laat tests eerst slagen.
2. Kies één kleine verbetering.
3. Verplaats of hernoem code.
4. Voer de tests opnieuw uit.

Maak geen grote verandering alleen omdat code er anders mooier uitziet. Een
duidelijke naam en een kleinere functie zijn vaak al een grote verbetering.
