# Leren Programmeren in Rust

Nederlandstalige mdBook-cursus voor beginnende programmeurs. De voorbeelden gebruiken een game als rode draad.

## Lokaal bouwen

Installeer Rust en mdBook en voer uit:

```text
mdbook serve
```

Open daarna de URL die mdBook toont.

## Online publiceren

De broncode staat in [keitv-codecraft/keitv-rust-basis-boek](https://github.com/keitv-codecraft/keitv-rust-basis-boek).
GitHub Actions bouwt het boek en publiceert het naar GitHub Pages.
